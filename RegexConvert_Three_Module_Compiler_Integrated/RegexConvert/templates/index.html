EXACT-LANGUAGE CONVERSION

Enter a literal string. The system constructs a concatenation of escaped literal symbols. The resulting regular expression recognizes the singleton language containing exactly that string—not every string in a broader pattern class.

Formal syntax & compiler algorithms

A concise reference for the supported formal regular-expression language and conversion methods.

Supported syntax

aLiteral symbol
abConcatenation
a|bAlternation / union
a*Zero or more
a+One or more
a?Optional
εEmpty string
∅Empty language
\|Escape special literal characters

Whitespace is ignored. This is formal regex syntax, not JavaScript/Python regex syntax; character classes and anchors are not supported.

Algorithms used

  1. Tokenizer + parserCreates tokens and an abstract syntax tree.
  2. Thompson's constructionBuilds an epsilon-NFA from the expression tree.
  3. Subset constructionUses epsilon-closure and state sets to construct a DFA.
  4. Partition refinementMinimizes a complete DFA.
  5. State eliminationGenerates a regular expression from a GNFA.
  6. Product-automaton BFSChecks equivalence and finds a distinguishing string.
